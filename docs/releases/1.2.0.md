# v1.2.0

## Highlights
- Async author scoring pipeline (`authors`, `author_scores`).
- Smart quality layer + weighted ranking precompute.
- Precomputed `feed_ranked_posts` serving path (`mode=ranked`).
- Worker migration safety scripts: `db:migrate:all` and `db:migrate:remote:all`.

## Deployment
Run from `artifacts/cf-worker`:

```bash
pnpm run db:migrate:remote:all
pnpm run deploy
```
