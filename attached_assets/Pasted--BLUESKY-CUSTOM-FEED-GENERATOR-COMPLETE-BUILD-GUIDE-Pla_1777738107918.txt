## 1. HOW IT ALL WORKS

```
BLUESKY APP (user)
      │
      │  GET /xrpc/app.bsky.feed.getFeedSkeleton?feed=at://YOUR_DID/...
      ▼
YOUR FEED GENERATOR SERVER (Replit)
      │
      │  Returns list of post URIs  [{post: "at://did.../post/abc"}, ...]
      ▼
BLUESKY APPVIEW
      │
      │  Hydrates posts (fetches text, likes, profile data)
      ▼
USER SEES FULL POSTS IN APP
```

### Key Concepts You MUST Understand

| Concept | What It Is |
|---|---|
| **Feed Generator** | Your Node.js server on Replit. Hosts one or more algorithms. |
| **DID** | Decentralized Identifier. Like a permanent ID for your server. You'll use `did:web:your-replit-url.replit.app` |
| **Firehose** | Real-time stream of ALL posts on Bluesky via WebSocket. You subscribe to this and filter. |
| **Jetstream** | Lighter-weight firehose alternative (JSON over WebSocket). Easier to work with. |
| **getFeedSkeleton** | The XRPC endpoint Bluesky calls on your server. You return post URIs. |
| **AT-URI** | Unique address for any Bluesky post: `at://did:plc:xxx/app.bsky.feed.post/yyy` |
| **Cursor** | Opaque pagination token. You define what it means. Typically `timestamp::postCID`. |
| **publishFeedGen** | Script you run ONCE to register your feed in your Bluesky account's repo. |

### `src/db.ts`

```typescript
import Database from 'better-sqlite3'
import { config } from './config'

let db: Database.Database

export function getDb(): Database.Database {
  if (!db) {
    db = new Database(config.sqliteLocation)
    db.pragma('journal_mode = WAL')   // Better concurrent read performance
    db.pragma('synchronous = NORMAL') // Balance safety vs speed
    initSchema(db)
  }
  return db
}

function initSchema(db: Database.Database) {
  db.exec(`
    CREATE TABLE IF NOT EXISTS post (
      uri        TEXT PRIMARY KEY,
      cid        TEXT NOT NULL,
      author     TEXT NOT NULL,
      text       TEXT NOT NULL,
      algo_tags  TEXT NOT NULL DEFAULT '',  -- comma-separated feed names
      indexed_at TEXT NOT NULL,
      likes      INTEGER DEFAULT 0
    );

    CREATE INDEX IF NOT EXISTS idx_post_indexed_at ON post(indexed_at DESC);
    CREATE INDEX IF NOT EXISTS idx_post_author ON post(author);
    CREATE INDEX IF NOT EXISTS idx_post_algo_tags ON post(algo_tags);

    CREATE TABLE IF NOT EXISTS sub_state (
      service TEXT PRIMARY KEY,
      cursor  INTEGER NOT NULL
    );
  `)
  console.log('[DB] Schema initialized')
}

export function upsertPost(post: {
  uri: string
  cid: string
  author: string
  text: string
  algoTags: string[]
  indexedAt: string
}) {
  const db = getDb()
  const stmt = db.prepare(`
    INSERT INTO post (uri, cid, author, text, algo_tags, indexed_at)
    VALUES (@uri, @cid, @author, @text, @algoTags, @indexedAt)
    ON CONFLICT(uri) DO UPDATE SET
      algo_tags = excluded.algo_tags,
      indexed_at = excluded.indexed_at
  `)
  stmt.run({
    uri: post.uri,
    cid: post.cid,
    author: post.author,
    text: post.text,
    algoTags: post.algoTags.join(','),
    indexedAt: post.indexedAt,
  })
}

export function deletePost(uri: string) {
  getDb().prepare('DELETE FROM post WHERE uri = ?').run(uri)
}

export function getSubState(service: string): number | undefined {
  const row = getDb()
    .prepare('SELECT cursor FROM sub_state WHERE service = ?')
    .get(service) as { cursor: number } | undefined
  return row?.cursor
}

export function updateSubState(service: string, cursor: number) {
  getDb()
    .prepare('INSERT OR REPLACE INTO sub_state (service, cursor) VALUES (?, ?)')
    .run(service, cursor)
}
```

### `src/algos/africa-dev.ts`

```typescript
import type { AlgoHandler } from '../types'
import { getDb } from '../db'

// Keywords that match Africa dev community posts
const KEYWORDS = [
  'kenya', 'nairobi', 'nigeria', 'lagos', 'ghana', 'accra',
  'africa', 'african', '#africandev', '#kenyadev', '#techkenya',
  'andela', 'kcb', 'mpesa', 'safaricom', 'swahili',
  'developer', 'coding', 'javascript', 'typescript', 'python',
  'react', 'nextjs', 'supabase', 'startup', 'fintech',
  'agritech', 'dripstech', '#buildinpublic',
]

export const africaDev: AlgoHandler = {
  // Called for every incoming post — return true to index it
  shouldIndex(post: { text: string; author: string }): boolean {
    const lower = post.text.toLowerCase()
    return KEYWORDS.some(kw => lower.includes(kw))
  },

  // Called when user requests the feed
  getFeed(limit: number, cursor?: string) {
    const db = getDb()

    let rows: { uri: string; cid: string; indexed_at: string }[]

    if (cursor) {
      const [cursorTimestamp] = cursor.split('::')
      rows = db
        .prepare(`
          SELECT uri, cid, indexed_at FROM post
          WHERE algo_tags LIKE '%africa-dev%'
            AND indexed_at < ?
          ORDER BY indexed_at DESC
          LIMIT ?
        `)
        .all(cursorTimestamp, limit) as typeof rows
    } else {
      rows = db
        .prepare(`
          SELECT uri, cid, indexed_at FROM post
          WHERE algo_tags LIKE '%africa-dev%'
          ORDER BY indexed_at DESC
          LIMIT ?
        `)
        .all(limit) as typeof rows
    }

    const feed = rows.map(row => ({ post: row.uri }))

    // Build next cursor from last item
    let nextCursor: string | undefined
    if (rows.length >= limit) {
      const last = rows[rows.length - 1]
      nextCursor = `${last.indexed_at}::${last.cid}`
    }

    return { feed, cursor: nextCursor }
  },
}
```

### `src/firehose.ts`

```typescript
import { Jetstream } from '@skyware/jetstream'
import { upsertPost, deletePost, updateSubState, getSubState } from './db'
import { algos } from './algos'
import { config } from './config'

export function startFirehose() {
  console.log('[Firehose] Connecting to Jetstream...')

  // Jetstream is a lighter WebSocket stream vs the full firehose
  // Endpoint options:
  //   wss://jetstream1.us-east.bsky.network/subscribe
  //   wss://jetstream2.us-east.bsky.network/subscribe
  //   wss://jetstream1.us-west.bsky.network/subscribe
  const jetstream = new Jetstream({
    wantedCollections: ['app.bsky.feed.post'],
    endpoint: config.subscriptionEndpoint,
  })

  jetstream.on('open', () => {
    console.log('[Firehose] Connected to Jetstream ✅')
  })

  jetstream.on('close', () => {
    console.log('[Firehose] Connection closed, reconnecting in 3s...')
    setTimeout(() => startFirehose(), config.subscriptionReconnectDelay)
  })

  jetstream.on('error', (err) => {
    console.error('[Firehose] Error:', err.message)
  })

  // Handle new posts
  jetstream.onCreate('app.bsky.feed.post', (event) => {
    const post = event.commit.record
    if (!post || typeof post.text !== 'string') return

    const postData = {
      text: post.text as string,
      author: event.did,
      langs: (post.langs as string[]) || [],
    }

    // Check which algos want this post
    const matchingAlgos: string[] = []
    for (const [name, algo] of Object.entries(algos)) {
      if (algo.shouldIndex(postData)) {
        matchingAlgos.push(name)
      }
    }

    if (matchingAlgos.length === 0) return

    // Index the post
    upsertPost({
      uri: `at://${event.did}/app.bsky.feed.post/${event.commit.rkey}`,
      cid: event.commit.cid,
      author: event.did,
      text: post.text as string,
      algoTags: matchingAlgos,
      indexedAt: event.time_us
        ? new Date(event.time_us / 1000).toISOString()
        : new Date().toISOString(),
    })

    console.log(`[Firehose] ⭐ Indexed for [${matchingAlgos.join(', ')}]: "${(post.text as string).substring(0, 60)}..."`)
  })

  // Handle deleted posts
  jetstream.onDelete('app.bsky.feed.post', (event) => {
    const uri = `at://${event.did}/app.bsky.feed.post/${event.commit.rkey}`
    deletePost(uri)
  })

  jetstream.start()

  return jetstream
}
```

### `src/auth.ts`

```typescript
import { Request, Response, NextFunction } from 'express'
import { AuthRequiredError, verifyJwt } from '@atproto/xrpc-server'
import { DidResolver, MemoryCache } from '@atproto/identity'
import { config } from './config'

const didCache = new MemoryCache()
const didResolver = new DidResolver(
  { plcUrl: 'https://plc.directory' },
  didCache
)

// Middleware: optionally verify the JWT from Bluesky
// For most feeds, auth is optional — Bluesky sends it but doesn't require you to verify
export async function verifyAuthOptional(
  req: Request,
  res: Response,
  next: NextFunction
) {
  const auth = req.headers.authorization
  if (!auth || !auth.startsWith('Bearer ')) {
    // No auth provided — fine for public feeds
    req.did = undefined
    return next()
  }

  try {
    const jwt = auth.replace('Bearer ', '')
    const payload = await verifyJwt(
      jwt,
      config.serviceDid,
      async (did: string) => {
        const doc = await didResolver.resolveAtprotoData(did)
        return doc.signingKey
      }
    )
    req.did = payload.iss
    next()
  } catch (err) {
    req.did = undefined
    next()
  }
}

// Extend Express Request type
declare global {
  namespace Express {
    interface Request {
      did?: string
    }
  }
}
```

### `src/routes/feed.ts`

```typescript
import { Router } from 'express'
import { algos } from '../algos'
import { verifyAuthOptional } from '../auth'

export const feedRouter = Router()

// GET /xrpc/app.bsky.feed.getFeedSkeleton?feed=at://DID/.../ALGO_NAME&limit=30&cursor=...
feedRouter.get(
  '/xrpc/app.bsky.feed.getFeedSkeleton',
  verifyAuthOptional,
  async (req, res) => {
    const feedUri = req.query.feed as string
    const limit = Math.min(parseInt(req.query.limit as string || '30'), 100)
    const cursor = req.query.cursor as string | undefined

    if (!feedUri) {
      return res.status(400).json({ error: 'MissingFeed', message: 'feed parameter required' })
    }

    // Extract the short record name from the AT-URI
    // Format: at://did:plc:xxx/app.bsky.feed.generator/RECORD_NAME
    const parts = feedUri.split('/')
    const algoName = parts[parts.length - 1]

    const algo = algos[algoName]
    if (!algo) {
      return res.status(404).json({
        error: 'UnsupportedAlgorithm',
        message: `Unknown feed: ${algoName}`,
      })
    }

    try {
      const result = algo.getFeed(limit, cursor)
      return res.json(result)
    } catch (err) {
      console.error(`[Feed] Error serving ${algoName}:`, err)
      return res.status(500).json({ error: 'InternalServerError' })
    }
  }
)
```

### `scripts/publishFeed.ts`

```typescript
/**
 * Run this ONCE to register your feeds with Bluesky.
 * Run again to UPDATE feed metadata.
 * 
 * Usage: npx ts-node scripts/publishFeed.ts
 */

import { AtpAgent, BlobRef } from '@atproto/api'
import { config } from '../src/config'
import * as fs from 'fs'
import * as path from 'path'
import dotenv from 'dotenv'
dotenv.config()

const BLUESKY_HANDLE = process.env.BLUESKY_HANDLE!       // e.g. yourname.bsky.social
const BLUESKY_APP_PASSWORD = process.env.BLUESKY_APP_PASSWORD!  // App Password, NOT your real password

async function publishFeed(feedConfig: typeof config.feeds[0]) {
  const agent = new AtpAgent({ service: 'https://bsky.social' })

  console.log(`\n[Publish] Logging in as ${BLUESKY_HANDLE}...`)
  await agent.login({
    identifier: BLUESKY_HANDLE,
    password: BLUESKY_APP_PASSWORD,
  })
  console.log('[Publish] Logged in ✅')

  // Optional: upload avatar
  let avatarRef: BlobRef | undefined
  const avatarPath = path.join(__dirname, `../assets/${feedConfig.recordName}-avatar.png`)
  if (fs.existsSync(avatarPath)) {
    const avatarBytes = fs.readFileSync(avatarPath)
    const blobRes = await agent.uploadBlob(avatarBytes, { encoding: 'image/png' })
    avatarRef = blobRes.data.blob
    console.log('[Publish] Avatar uploaded ✅')
  }

  // Create/update the feed generator record
  await agent.com.atproto.repo.putRecord({
    repo: agent.session!.did,
    collection: 'app.bsky.feed.generator',
    rkey: feedConfig.recordName,
    record: {
      did: config.serviceDid,
      displayName: feedConfig.displayName,
      description: feedConfig.description,
      avatar: avatarRef,
      createdAt: new Date().toISOString(),
    },
  })

  const feedUri = `at://${agent.session!.did}/app.bsky.feed.generator/${feedConfig.recordName}`
  console.log(`[Publish] ✅ Feed published!`)
  console.log(`[Publish] AT-URI: ${feedUri}`)
  console.log(`[Publish] View on Bluesky: https://bsky.app/profile/${BLUESKY_HANDLE}/feed/${feedConfig.recordName}`)
}

async function main() {
  for (const feed of config.feeds) {
    await publishFeed(feed)
  }
}

main().catch(err => {
  console.error('[Publish] Error:', err.message)
  process.exit(1)
})
```

```typescript
  getFeed(limit, cursor) {

  }
}
```

## 13. ADVANCED: AI-POWERED FEED

Use Anthropic Claude API to intelligently score and filter posts.

### Install

```bash
npm install @anthropic-ai/sdk
```

### Add Secret in Replit

`ANTHROPIC_API_KEY` = your Anthropic API key

### AI Scoring Algo

```typescript
// src/algos/ai-scored.ts
import Anthropic from '@anthropic-ai/sdk'

const anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY })

// Cache scores to avoid re-calling API (save costs)
const scoreCache = new Map<string, number>()

export async function scorePost(text: string): Promise<number> {
  if (scoreCache.has(text)) return scoreCache.get(text)!

  const response = await anthropic.messages.create({
    model: 'claude-haiku-4-5-20251001', // Use Haiku — cheapest, fast enough
    max_tokens: 10,
    messages: [{
      role: 'user',
      content: `Rate this post 0-10 for relevance to African agritech/irrigation/farming. Just respond with a single number.

Post: "${text.substring(0, 200)}"`
    }]
  })

  const score = parseFloat(
    (response.content[0] as { type: 'text'; text: string }).text.trim()
  ) || 0

  scoreCache.set(text, score)
  return score
}
```

> 💡 **Cost tip**: Run AI scoring async in background, not in the hot path. Score posts as they're indexed, not when Bluesky requests the feed.

## 18. COMMON ERRORS & FIXES

| Error | Cause | Fix |
|---|---|---|
| `"Unsupported Algorithm"` | Wrong record name in AT-URI | Match `recordName` in config to algo key in `algos/index.ts` |
| `"invalid feed generator service details"` | DID doc not resolving | Check `/.well-known/did.json` is accessible publicly |
| `process.env.X is undefined` | Secret not set in Deployment | Add secrets in Deployments tab separately |
| `EADDRINUSE port 3000` | Port already in use | Change `PORT` secret or kill other processes |
| Feed shows 0 posts | Firehose not indexing | Check keywords, check console for `⭐ Indexed` messages |
| `SQLITE_IOERR` | Disk write error on Replit | Use `:memory:` for dev, set `FEEDGEN_SQLITE_LOCATION=feed.db` for prod |

| Firehose disconnects constantly | Jetstream endpoint unreachable | Try alternate endpoint: `wss://jetstream1.us-west.bsky.network/subscribe` |

## 19. CURSOR PAGINATION

Cursors are opaque strings that let Bluesky fetch older posts. Best practice: `timestamp::cid`

```typescript
// Encoding cursor
const cursor = `${lastPost.indexed_at}::${lastPost.cid}`
// e.g.: "2024-05-01T14:32:00.000Z::bafyreiamna..."

// Decoding cursor
const [timestamp, cid] = cursor.split('::')

// Using in SQL
db.prepare(`
  SELECT * FROM post
  WHERE indexed_at < ?           -- posts OLDER than cursor
  ORDER BY indexed_at DESC
  LIMIT ?
`).all(timestamp, limit)
```

### Rules for Cursors
- Must be **unique per feed item** — never duplicate
- Treated as **opaque** by Bluesky (they just pass it back to you)
- If your last page has fewer items than `limit`, return `cursor: undefined`
- Per Bluesky docs: compound `timestamp::CID` is the recommended format

## 20. DID:WEB vs DID:PLC

| | `did:web` | `did:plc` |
|---|---|---|
| **Setup** | Automatic — uses your domain | Requires registration on plc.directory |
| **Portability** | Tied to your hostname | Can migrate domains freely |
| **Stability** | Changes if you change domain | Permanent |
| **Replit suitability** | ✅ Perfect for free Replit URL | Overkill for starting out |
| **Recommended for** | Development, starting out | Long-term production feeds |

**Start with `did:web`** — it works automatically on Replit. Migrate to `did:plc` when/if you move to a custom domain (e.g., `feeds.dripstech.co.ke`).

To switch to `did:plc`:
1. Register at https://plc.directory
2. Set `FEEDGEN_SERVICE_DID=did:plc:YOUR_PLC_ID` in secrets
3. Re-run publish script

## 21. COST & SCALING CONSIDERATIONS

### Free Tier (Development)
- Replit free tier: Repl sleeps after inactivity
- Not suitable for production — Bluesky needs 24/7 responses
- Use for: building, testing, demoing

### Replit Reserved VM (Production)
- ~$7/month for smallest tier
- Always-on, persistent disk, HTTPS included
- Suitable for: up to ~10k feed requests/day

### Scaling Beyond Replit
When your feed gets popular:

| Load | Solution |
|---|---|
| 10k req/day | Replit Reserved VM |
| 100k req/day | Add Cloudflare CDN in front |
| 1M+ req/day | Move to Cloudflare Workers + D1 (your existing DripsTech stack!) |

### Firehose CPU Cost
The Jetstream firehose delivers millions of posts/day. Your `shouldIndex()` function runs on EVERY post. Keep it fast:
- Simple string `.includes()` checks: ✅ Fast
- Regex: ⚠️ Slower but okay
- API calls in `shouldIndex()`: ❌ Never — will crash under load
